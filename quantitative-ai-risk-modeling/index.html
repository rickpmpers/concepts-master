SECTION 01
Continuous Telemetry vs Point-in-Time
  • Shifts from static qualitative cyber questionnaires to dynamic, automated CI/CD and runtime evaluation sidecars.
  • Embeds open-source harnesses into policyholder build pipelines to extract deterministic vulnerability scores.
  • Bridges the market gap between technical vulnerability metrics and carrier solvency reserves.
SECTION 02
FAIR Parameter Translation
  • Loss Event Frequency (LEF): Calculated as Threat Event Frequency (TEF) × Vulnerability (V).
  • Vulnerability (V): Direct failure rate aggregate derived from red-team jailbreaks, evasion rates, and hallucination metrics.
  • Threat Frequency (TEF): Inferred from production API monitoring, anomalous queries, and untrusted inputs per unit time.
SECTION 03
Agent Tool Blast-Radius Weighting
  • Calculates Loss Magnitude (LM) weighted by Model Context Protocol (MCP) tool scopes.
  • Primary Loss: S_tool × Max_Transaction_Limit + Compute_Runaway_Cost + Remediation_Cost.
  • S_tool Blast Radius: Ranges from 0.05 for read-only sandboxes to 0.95 for arbitrary system execution.
SECTION 04
Stochastic Monte Carlo & Policy Caps
  • 50,000 stochastic Monte Carlo iterations parameterized by Beta-PERT distributions and Lognormal asset loss curves.
  • 99.5% Value-at-Risk (VaR): Establishes maximum baseline loss expectation over annual policy windows.
  • Tail Value-at-Risk (TVaR): Quantifies catastrophic multi-agent cascading loops to set non-negotiable aggregate liability caps.
