Architecture & Zero-Overhead Design

Traditional desktop monitoring widgets (Electron apps, WebViews, Conky overlays) constantly poll system APIs at 1–60 Hz, competing with local AI model inference for memory and CPU cycles. GPUpower replaces this overhead by decoupling telemetry generation into a headless oneshot Python rasterizer driven by a native user-level systemd timer.

Wayland Double-Buffering

GNOME Shell caches wallpaper URIs aggressively to avoid redundant disk reads. To guarantee an immediate repaint without visual artifacts or desktop restarts, GPUpower alternates between two disk targets (wallpaper_0.png and wallpaper_1.png) on each 5-minute cycle, triggering GNOME's GSettings change handler seamlessly.
